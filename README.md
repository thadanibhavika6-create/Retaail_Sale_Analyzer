## 📌 About the Project

**NumPy Analyzer** is an interactive Python application that lets you explore the core concepts of the `numpy` library through a simple, user-friendly menu. From creating 1D, 2D, and 3D arrays to performing mathematical operations, searching, sorting, filtering, and statistical analysis — everything is built on a clean, well-structured OOP foundation.

## 🎯 Features

| # | Feature | Description |
|---|----------|-------------|
| 🧱 | **Array Creation** | Build 1D, 2D, or 3D arrays from user input |
| 🔍 | **Indexing & Slicing** | Flat indexing and 2D slicing support |
| ➕ | **Mathematical Operations** | Addition, Subtraction, Multiplication, Division, Dot Product, Matrix Multiplication |
| 🔗 | **Combine & Split** | Stack arrays together or split them into parts |
| 🔎 | **Search, Sort & Filter** | Search for a value, sort the array, or apply condition-based filters |
| 📈 | **Aggregates & Statistics** | Sum, Mean, Median, Std Dev, Variance, Min, Max, Percentile, Correlation |
| 🏗️ | **OOP Concepts** | Real-world use of Static, Class, and Private methods |

```bash

cd numpy-analyzer
```


## 🖥️ How It Works

As soon as you run it, a clean menu opens up:

```
=============================================
        NUMPY ANALYZER
=============================================

Welcome to the NumPy Analyzer!
1. Create a NumPy Array
2. Indexing and Slicing
3. Mathematical Operations
4. Combine or Split Arrays
5. Search, Sort, or Filter Arrays
6. Compute Aggregates and Statistics
7. Exit
```

Just pick a number and start exploring your array! 🎉

## 🧠 Key Concepts Covered

- Object-Oriented Programming (Constructor, Static, Class & Private methods)
- NumPy array creation aur reshaping (1D / 2D / 3D)
- Array slicing & flat indexing
- Element-wise math + matrix operations (`@`, `np.dot`)
- `np.vstack`, `np.concatenate`, `np.array_split`
- `np.where`, `np.sort`, boolean filtering
- Statistical functions: `mean`, `median`, `std`, `var`, `percentile`, `corrcoef`
